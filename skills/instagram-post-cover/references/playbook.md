# 유형별 제작 가이드

아래는 선정 사례에서 읽은 제작 방향이다. 전수 측정 결과나 사용자 발언이 아니다. 번호는 `catalog.json`의 key를 가리킨다. 원문 URL은 `scripts/list_references.py --ids <key>`로 찾는다. 유형은 겹칠 수 있다.

| 유형 / 태그 | 먼저 볼 통과 사례 | 구도와 제목의 관계 |
|---|---|---|
| 사진 + 헤드라인 / `photo-headline` | b01-003, b01-004, b02-105, b02-294 | 인물·사건·공간이 화면의 중심. 아래쪽 짧은 굵은 제목. 필요한 영역만 어둡게 하며 사진 자체가 주제를 설명하게 한다. |
| 외곽선 후킹 / `outlined-hook` | b01-014, b01-020, b02-263, b02-288 | 복잡한 실제 사진 위의 굵은 글자와 외곽선. 핵심 단어에만 색을 준다. 외곽선 두께가 글자 속공간을 막지 않게 한다. |
| 생활·취향 에디토리얼 / `lifestyle-editorial` | b02-103, b02-108, b02-138, b02-246, b02-267 | 옷·공간·취향의 구체적 이미지가 먼저 보인다. 명조·고딕 모두 가능. 작은 잡지 장식보다 주제와 연결된 큰 문구를 우선한다. |
| 음식·장소 발견 / `food-place` | b01-026, b02-108, b02-139, b02-269 | 음식 질감이나 장소 특징을 가리지 않는다. 무엇을 먹거나 어디를 가는지와 추천 이유가 한눈에 드러나는 제목. 필요한 경우 작은 목록 수/장소 표기. |
| 제품 발견 / `product-discovery` | b02-116, b02-260, b02-267, b02-288 | 실물 디테일과 착용/사용 맥락을 확보. '왜 관심을 가질까'를 한 문장으로. 무조건 할인 전단으로 처리하지 않는다. |
| 텍스트 한 방 / `text-one-liner` | b02-132, b02-274 | 짧은 완결된 생각과 의미 단위 줄바꿈. 단순 배경, 내용에 맞는 서체. 사진을 억지로 채우지 않는다. 짧다고 자동 통과하는 유형은 아니다. |
| 캡처·밈 / `screenshot-meme` | b01-027, b01-039, b02-109, b02-123, b02-136, b02-254 | 원본의 웃음/정보 포인트가 보이는 크롭과 짧은 프레이밍 문구. 웹 원문을 확보하고 출처를 유지한다. 대화나 댓글을 조작해 증거처럼 보이게 하지 않는다. |
| 비교·콜라주 / `comparison-collage` | b01-028, b02-115, b02-130 | 비교 이유가 명확한 여러 이미지와 하나의 결론. 각 패널 크기와 시선 순서를 정한다. 작은 이미지·본문을 무더기로 넣지 않는다. |

## 시작값

1080px 폭에서 좌우 여백 약 48–72px, 제목 약 72–110px, 대개 2–3줄을 출발점으로 삼을 수 있다. 이는 측정 통계가 아니다. 글자 수·서체·피사체에 따라 조절하고 작은 피드 미리보기로 판단한다. 긴 제목이면 글자를 계속 줄이기보다 문구를 줄인다. 텍스트형·캡처형에는 사진형의 하단 제목 공식을 강제하지 않는다.

검정 그라디언트는 텍스트 가독성이 필요할 때만 쓴다. 모든 사진을 과하게 어둡게 만들지 않는다. 흰색 굵은 제목이 자주 보이지만 서체·색·정렬 하나를 만능 정답으로 만들지 않는다.

## 탈락본과 함께 비교할 것

- 텍스트형: 통과 b02-132/b02-274와 탈락 b02-006/b01-089. 단순 배경이나 손글씨 자체로 통과/탈락을 설명할 수 없다.
- 정보 밀도: 통과 b02-123과 탈락 b02-001. 작은 피드에서 무엇이 먼저 읽히는지 비교한다. 주제 선호의 영향도 있을 수 있다.
- 큰 제목: 통과 b02-105와 탈락 b02-024. 큰 글자·노랑 포인트만 복제해도 사용자 취향이 보장되지는 않는다.
- 그림/만화: 통과 b01-008과 탈락 b02-033. 일러스트는 전면 금지가 아니다. 다만 새로운 일러스트도 웹에서 가져와야 한다.

탈락본을 보며 이유를 질문받으면 관찰 가능한 차이와 가설만 설명한다. '사용자가 이 색/폰트를 싫어한다'고 확정하지 않는다. 참고 이미지에 있는 자극적인 사실 주장은 새 제작의 검증 자료로 쓰지 않는다.
